# Human interface

The home page lists projects. Users can create a project, choose Default, Linear, or Git mode, manage members, open files, and start conversations when hosted execution is available.

The project interface keeps file editing and conversations together. Switching tabs preserves drafts. Conflicting saves retain edits and provide a recovery path. Read-only roles and archived state disable writes.

Project settings and Agent connect are available from the project navigation. Account settings manage identity, authentication, external agent keys, and model providers. Agent connect supplies the project ID and connection instructions without embedding credentials.

Public project visitors see the name and description. The UI must not imply that public visibility publishes files or conversations. Removed research routes show page recovery rather than a research editor.
