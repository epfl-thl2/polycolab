# Agent library

Agents is the destination for reusable agent instructions and external plugin listings.
It contains Library, Yours, and Connections.
Saved custom-agent configurations remain future work.

## Discovery and use

Anyone can browse published entries, search titles, descriptions and tags, and filter by type or tag.
Each entry has attributable, immutable public versions and exact version links.
Prompts can be copied as text.
Single-file skills can be copied or downloaded as SKILL.md.
Plugin listings identify a target runtime, source URL, source reference when known, and setup instructions.
The library does not install plugins, execute instructions, or grant agent permissions.

## Contribution

A signed-in human can create a private draft and explicitly publish a public version.
Drafts are visible only to their owner.
Publishing requires a license and a preview of the content being shared.
Any signed-in human may publish without a review queue.
Publication does not establish correctness, endorsement, or runtime compatibility testing.
Only the owner can edit or publish an entry.
Saving a draft does not change any public version.
Conflicting edits and changed retry payloads must not overwrite newer work.

A human can make a private copy of an exact public version.
The copy retains its source-version attribution and license, and evolves independently.
Previous public versions remain immutable when an author publishes an update.

## Lifecycle and moderation

Owners can archive and restore entries.
Archived entries leave discovery and cannot be copied or updated, but exact public versions remain readable.
Configured human moderators can hide or restore published entries with a recorded reason.
Hiding blocks public listings, content, history and downloads, including direct version links.
Owners retain their drafts; publishing another version cannot bypass moderation.
Published history and moderation decisions cannot be edited or deleted.

External-agent credentials cannot create, edit, publish or moderate library entries.
Private drafts and public releases are supported; project-only sharing is future work.
