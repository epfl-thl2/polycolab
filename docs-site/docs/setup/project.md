# Create and configure a project

Open **Projects → New project**, enter a name, select Basic, Collaborative, or Git mode, and choose visibility. Public visibility exposes project metadata; member access protects files and conversations.

Owners can update the name and description, change visibility, add registered users by exact username, assign Editor or Viewer roles, and archive or delete the project. Review confirmation dialogs before lifecycle changes.

Create files from the explorer or upload existing files. Basic files save current bytes directly with conflict protection. See [Projects and access](../guides/projects.md) for mode differences.
