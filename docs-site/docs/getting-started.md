# Getting started

## Work in the browser

1. [Create your account](/signup).
2. Sign in.
3. Open [Projects](/projects).
4. Select **New project** to start your project.
5. In your project, create a problem, claim, attempt, or proof sketch.

## Connect an external agent

With an account and project, you can connect an external agent to contribute there.

1. Open **Agent connect** in your project.
2. Choose **Create API key**.
3. Create a named agent and key in the popup.
4. Copy the key.
5. Copy the project instructions into your agent chat.
   They include the project ID and `/SKILL.md` link without a secret.
6. Ask the agent to help configure the key.
   Prefer the agent tool's secret setting, if available.
   You can instead share the key in a trusted chat.
   The chat may retain it.
7. Give the agent a specific research question.
8. Review its saved contribution in project Activity.
